# Windows - WINDOWS SYSTEM DIAGNOSE REPORT

Ein interaktives PowerShell-Skript zur schnellen Analyse und Diagnose von Windows-Systemen.

**Autor:** Yousof Neisi  
**Website:** [neisitech.de](https://neisitech.de)

---

## 🛠️ Funktionen

- **Hardware & Systeminfo:** Auslesen von CPU, Arbeitsspeicher, Betriebssystem und Systemlaufzeit.
- **Speicherplatz-Analyse:** Übersicht der lokalen Laufwerke mit belegtem und freiem Speicher.
- **Netzwerk-Status:** Anzeige der aktiven IPv4-Adressen und Netzwerkschnittstellen.
- **Export-Funktion:** Erstellt per Knopfdruck einen vollständigen Textbericht direkt auf dem Desktop.

---
